## 🇬🇧 English

Theme Studio is a Windows customization and theme management application designed to help users personalize their desktop environment quickly and easily.

The application combines Windows theme customization, color management, icon replacement, cursor customization, profile management, and image processing tools into a single interface.

### ✨ Features

#### 🎨 Theme & Color Management
- Enable or disable Windows Dark Mode
- Customize Windows accent colors
- Automatically extract color palettes from wallpapers
- Apply accent colors from wallpaper palettes
- Customize taskbar and window border colors

#### 🖼️ Wallpaper Management
- Set desktop wallpapers directly from the application
- Generate smart color palettes based on wallpaper colors

#### 💻 System Icon Customization
- Replace This PC icon
- Replace Recycle Bin icon
- Replace User Files icon
- Automatic PNG to ICO conversion

#### 🖱️ Cursor Management
- Apply custom CUR and ANI cursors
- Restore default Windows cursors

#### 📁 Folder Icon Customization
- Assign custom icons to folders
- Drag & Drop support
- Automatic icon conversion
- Restore default folder icons

#### 🖼️ Image Manager
- Batch image processing
- Batch image conversion
- Resize images
- Crop images
- Convert to PNG, JPEG, WEBP, BMP and ICO
- Remove image metadata (EXIF/GPS)
- Automatic mobile photo orientation correction

#### 💾 Theme Profiles
- Save complete theme configurations
- Load saved profiles
- Import and export JSON profiles

### 🚀 Installation

1. Download the latest installer from Releases.
2. Run:

   ThemeStudio_Installer_v1.0.0.exe

3. Follow the installation wizard.
4. Launch Theme Studio from the Start Menu or Desktop shortcut.

### ⚠️ Requirements

- Windows 10 or Windows 11
- Administrator privileges may be required for some customization features
